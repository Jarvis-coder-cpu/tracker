# 🔥 Fire Loss Tracker - Quick Reference Card

## 🚀 First Time Setup (2 minutes)

```
1. Open app in Chrome/Samsung Internet
2. Tap "Install" in blue banner OR menu (⋮) → "Add to Home screen"
3. When recording, tap "Allow" for microphone
4. Done! Start recording items
```

## 🎤 Enable Microphone (If Denied)

```
🔒 Tap lock icon in address bar
→ Permissions
→ Microphone
→ Allow
→ Reload page
```


## 🔧 Common Issues & Quick Fixes

| Problem | Solution |
|---------|----------|
| **"Microphone permission denied"** | Tap 🔒 in address bar → Permissions → Microphone → Allow |
| **"Speech recognition not supported"** | Use Chrome on Android or Safari on iOS (not Firefox) |
| **"Requires HTTPS"** | Install as PWA via menu (⋮) → "Add to Home screen" |
| **Items not saving** | Don't use incognito mode; ensure storage permission |
| **No speech detected** | Speak louder; reduce background noise |

## 📤 Export Process

```
1. Fill in claim info at top:
   - Claim Number
   - Your Name
   - Phone Number

2. Record all items

3. Tap "Export CSV" 📥

4. Share file with insurance adjuster
```

## 🎯 Best Practices

### ✅ DO:
- Speak one item at a time
- Include brand, room, and cost when known
- Review each item after recording
- Export frequently as backup
- Install as app for best experience

### ❌ DON'T:
- Use incognito/private mode
- Clear browser data without exporting
- Record multiple items in one recording
- Mumble or speak too quietly
- Skip the claim information fields

## 🎓 Voice Recognition Tips

### Speak Clearly:
```
✅ "Samsung 55-inch TV, living room, eight hundred dollars"
❌ "uh... we had this like... Samsung thing... maybe 55 inches..."
```

### Include Context:
```
✅ "Sony headphones, WH-1000XM4, bought from Best Buy for $350"
✅ "Kitchen table, IKEA, oak finish, about 3 years old"
```

### One Item Per Recording:
```
✅ Record → "Coffee maker" → Stop → Record → "Toaster" → Stop
❌ Record → "Coffee maker, toaster, and blender" → Stop
```

## ⚙️ Advanced Features

### Duplicate Detection:
App automatically asks if similar items should be merged or kept separate.

### Smart Parsing:
Understands context - "bought it at Target" extracts "Target" as store.

### Quantity Shortcuts:
"Two TVs" or "a pair of shoes" automatically sets quantity.

### Age Calculation:
"3 years old" automatically calculates purchase year.

## 🆘 Emergency Troubleshooting

### App Won't Load:
```bash
1. Clear browser cache
2. Force close browser
3. Reopen and try again
```

### Microphone Stuck:
```bash
1. Close app completely
2. Restart browser
3. Reopen app
4. Try recording again
```

### Data Lost:
```bash
⚠️ Cannot recover without backup
Always export CSV regularly!
```
